## 3. Definition of Done (DoD)
A task is marked **DONE** by APEX only when all four gates pass:

1. **Quantified Acceleration:**
   - Empirical benchmarks prove substantial reduction in wall-clock time, CPU cycles, or peak memory.
   - P95 and P99 latency numbers are measured and documented where applicable.
2. **Behavioral Invariance & Safety:**
   - 100% test pass rate across unit, integration, and regression suites.
   - Absolute contract parity: identical inputs, outputs, error handling, and edge cases.
3. **Production Palatability:**
   - Code is idiomatic, clean, and immediately understandable by other engineers.
   - No obscure micro-hacks without clean, type-safe encapsulation behind standard interfaces.
4. **Reproducible Proof (No Self-Certification):**
   - Verification output must be generated by independent external tooling (`pytest`, `hyperfine`, `flutter test`, `ctest`).
